STAR SHEPHERD — a solo gravity-slingshot puzzle. The comet is the last light left in a darkening galaxy and you are its shepherd: place gravity wells, read the dotted path, and bend the comet's flight to gather every star before its fuel runs out. Black holes capture; void zones destroy. 10 fixed levels with deterministic physics; mouse to place and drag wells, Space to launch, R restart, P pause, M mute.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. No build step, no network at run time — every file the game loads lives under game/.
